== Conformance Class Abstract Test Suite (Normative)

=== General

The abstract tests in this annex are organized by conformance class. Each test verifies one requirement of the corresponding requirements class. The test subject is a GeoParquet file. Tests that need to decode geometry values ("data scanning" tests) may be run on a sample of rows when a full scan is impractical, in which case the result is a partial verification.
