EDITORIAL STATUS (remove before submission)

This is a proposal prepared on the ogc-spec-alignment branch. It restates the GeoParquet
2.0.0 community specification (format-specs/geoparquet.md, format-specs/schema.json) as an
OGC Standard. Open items that the SWG has to confirm:

* docnumber 24-013 was assigned by OGC in 2024 for the 1.0 draft; confirm with OGC staff
  that it is still reserved for GeoParquet.
* received/issued/published dates are placeholders (date of drafting).
* editors (fullname..fullname_5) and submitting organizations are carried over from PR #224.
  The chair considers the five names correct but expects that others are needed
  (for example the authors of the 2.0 changes). @cholmes: who else should be listed as
  editor, and who as contributor in clause 0? The Contributors table is a placeholder.
* Clause 7 (Bounding Box Covering) restates pull request #302, merged into the community
  specification on 2026-09-07.
* The normative reference to the GeoParquet JSON Schema points at the v2.0.0 release URL,
  which exists only once 2.0.0 is tagged.

See docs/ogc/CHANGES.md for every place where the wording here differs from the markdown.
