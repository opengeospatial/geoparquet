[[rec_core_crs-srid-zero]]
[recommendation]
====
[%metadata]
identifier:: /rec/core/crs-srid-zero
part:: If the `crs` member of a column metadata object is `null`, the `crs` parameter of the column's `GEOMETRY` or `GEOGRAPHY` logical type SHOULD be the string `srid:0`.
